# CRM GP7

Sistema de CRM desenvolvido para a GP7 Distribuidora, com foco em centralizar informações e facilitar o acompanhamento de processos e atividades da operação comercial.

## Status

🚧 **Em desenvolvimento**

O sistema está sendo desenvolvido e aprimorado continuamente de acordo com as necessidades identificadas na operação da empresa.

## Sobre o projeto

O CRM GP7 foi criado com o objetivo de centralizar informações e facilitar o gerenciamento de dados e processos comerciais em uma única plataforma.

A aplicação está sendo desenvolvida de forma personalizada, considerando os fluxos de trabalho e necessidades observadas no ambiente da empresa.

O projeto envolve desenvolvimento de interface, organização de dados, integração com banco de dados e construção de funcionalidades voltadas para uma aplicação de uso corporativo.

## Funcionalidades

- Centralização de informações da operação
- Interface para gerenciamento de dados
- Organização de informações comerciais
- Integração com banco de dados
- Estrutura preparada para evolução e inclusão de novas funcionalidades
- Interface responsiva para diferentes dispositivos

## Tecnologias

- React
- TypeScript
- Vite
- Supabase
- Tailwind CSS

## Desenvolvimento

O Lovable foi utilizado como ferramenta de apoio durante parte do desenvolvimento inicial.

A aplicação está sendo continuamente adaptada, configurada e aprimorada de acordo com as necessidades do projeto.

O desenvolvimento também envolve ajustes na estrutura da aplicação, organização dos dados, implementação de funcionalidades e integração com o ambiente de banco de dados.
