# CRM GP7

Sistema de CRM desenvolvido para a GP7 Distribuidora.

## Status

Em desenvolvimento.

O projeto está sendo desenvolvido e aprimorado de acordo com as necessidades da operação da empresa.

## Sobre o projeto

O CRM GP7 tem como objetivo centralizar informações e facilitar o acompanhamento da operação comercial em uma única plataforma.

A aplicação está sendo construída de forma personalizada, considerando os processos e necessidades identificados no ambiente da empresa.

## Tecnologias

- React
- TypeScript
- Vite
- Supabase
- Tailwind CSS

## Desenvolvimento

O Lovable foi utilizado como ferramenta de apoio durante parte do desenvolvimento inicial do projeto.

A aplicação está sendo continuamente adaptada, configurada e aprimorada conforme a evolução do projeto e as necessidades da GP7.
